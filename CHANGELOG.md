# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии инструмента следуют [Semantic Versioning](https://semver.org/lang/ru/).
Версии стандарта ведутся отдельно в `SPEC/CHANGELOG.md`.

## [0.11.1] — 2026-08-14

### Исправлено

- reply на пересланного родителя теперь использует подтверждённого исходного
  автора, а не человека, который переслал сообщение;
- скрытое авторство родителя остаётся неподтверждённым.

### Инфраструктура

- добавлен GitHub CI для selfcheck и unit-тестов;
- закреплены правила тегов и GitHub Releases для версий инструмента.

## [0.11.0] — 2026-08-14

### Добавлено

- `people --update` для безопасного дополнения существующей записи;
- импорт и отображение `reply_context` из Herald;
- unit-тесты поведения команд и provenance ответов.
