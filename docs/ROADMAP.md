# ROADMAP — mnemo

_Фазами. Каждая фаза самодостаточна и что-то даёт уже сейчас._

## Phase 0 — Foundation (сейчас)
- [x] Спек: VISION / ARCHITECTURE / компоненты
- [x] Раскладка стора «RAW + summaries + index» обкатана руками (прототип chat-export)
- [ ] Зафиксировать схему `item` и формат INDEX как контракт
- [ ] Скелет ядра: пустые модули `connectors/`, `core/`, `adapters/`

**Даёт:** ясную основу, по которой можно писать не размышляя об архитектуре.

## Phase 1 — chat-export (автоматизация прототипа)
- [ ] Парсер экспорта Telegram → RAW (messages + attachments + screenshots)
- [ ] Извлечение текста и картинок из docx/xlsx (уже есть рабочий скрипт-черновик)
- [ ] Авто-генерация `summaries/` + `INDEX.md`
- [ ] CLI: `mnemo ingest <path>`

**Даёт:** то, что сейчас делается руками, — одной командой.

## Phase 2 — retrieval (мозг)
- [ ] normalize → chunks → embeddings → vector index
- [ ] `mnemo ask "<вопрос>"` → ответ со ссылкой на RAW
- [ ] Структурные фильтры: проект / дата / участник / источник / контур

**Даёт:** поиск по всей памяти вместо ручного скролла.

## Phase 3 — MCP / skill
- [ ] MCP-сервер поверх `retrieve` — ассистент запрашивает память как инструмент
- [ ] Оформить как skill

**Даёт:** ассистент отвечает «что решили по X» с цитатой, сам.

## Phase 4 — dailies
- [ ] Коннектор к дейликам (по дням/проектам)
- [ ] Связка дейлик ↔ остальной контекст: «что делал по проекту за неделю»

**Даёт:** рабочие логи в общем поиске.

## Phase 5 — tg-adapter
- [ ] TG-бот: диалог с ассистентом + запрос памяти + grep
- [ ] Отметка в дейлике из бота

**Даёт:** доступ к системе с телефона, без терминала.

## Phase 6 — chat-sync
- [ ] Синк транскриптов диалогов ассистента, шифрованно, через git
- [ ] Работа с ними: поиск / удаление / форк веток разговора

**Даёт:** история диалогов доступна между машинами и безопасна.

---

### Порядок неслучаен
Сначала **надёжное хранилище** (0–1), потом **поиск** (2), потом **доступ**
(3–5), в конце — **синк истории** (6). Каждый слой опирается на предыдущий;
поиск без надёжного RAW бессмысленен, синк без поиска — просто бэкап.
