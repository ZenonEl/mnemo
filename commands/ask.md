Используй навык **mnemo:chat-export**.

**Завести** — три поля обязательны, команда откажется без них:
```
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/mnemo_manifest.py ask --export <dir> \
  --text "<вопрос>" --impact "<что будет сделано иначе>" \
  --asked-of "<кто реально ответит>" --based-on "ctx:<slug>#iNNN" \
  [--blocking "<что стоит без ответа>"]
```

Что проверить по каждому полю — в навыке, раздел «Заслон на вопросы». Коротко:
`--impact` называет, что изменится **в коде или конфигурации**, а не «будет
понятнее»; `--asked-of` — человек из реестра, который правда владеет ответом
(если решаем сами — это не вопрос); `--based-on` — материал, который ты открыл
и в котором вопрос действительно возник.

**Завести пачкой:**
```
... ask --export <dir> --batch voprosy.md --asked-of "<у кого>"          # план
... ask --export <dir> --batch voprosy.md --asked-of "<у кого>" --apply  # запись
```
По вопросу на строку, хвост после `::` — ссылки `based_on`. Отметки
«спросили» / «отвечено» к пакету не применяются: они про конкретный вопрос.

**Отметить, что спросили:**
```
... ask --export <dir> --id qNNN --raised-to "<кому>" --where "дейлик <репо>#110"
```

**Закрыть:**
```
... ask --export <dir> --id qNNN --answered-by "ctx:<slug>#iNNN"
```

## Что важно

**Вопрос закрывается ссылкой, а не словом.** `--answered-by` указывает на
материал, факт или требование, которое дало ответ. Голое «отвечено» — это
утверждение, которому нечем возразить; ссылку проверяет линтер.

**Состояние не хранится, а выводится**: есть ответ — `answered`, есть отметки
«спрашивали» — `raised`, иначе `open`. Поэтому оно не может разойтись с
содержимым.

**`--raised-to` обязательно отмечай, когда вопрос ушёл человеку.** Иначе
следующая сводка поднимет его заново как новый, и ты второй раз спросишь то, что
уже спрашивал. Отметки накапливаются: спросили дважды — две записи.

**`--impact` — что меняется от ответа.** Проверка простая: назови два исхода
ответа и для каждого — что конкретно будет сделано иначе. Оба ведут к тому же
коду — это не вопрос, а любопытство.

**Похожий вопрос команда покажет и откажется писать** без явного решения:
отметить существующий (`--id`), либо подтвердить, что это правда другое
(`--anyway`). Слить их сама она не вправе.

**Протухшее видно отдельно.** Вопрос, спрошенный больше недели назад без
ответа, попадает в секцию «ПРОТУХЛО» — его переспрашивают или снимают
(`--dropped-reason`), а не ждут дальше.
