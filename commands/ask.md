Используй навык **mnemo:chat-export**.

**Завести:**
```
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/mnemo_manifest.py ask --export <dir> \
  --text "<вопрос>" --impact "<что меняется от ответа>" \
  [--blocking "<что стоит без ответа>"] [--asked-of "<у кого>"]
```

**Отметить, что спросили:**
```
... ask --export <dir> --id qNNN --raised-to "<кому>" --where "дейлик <репо>#110"
```

**Закрыть:**
```
... ask --export <dir> --id qNNN --answered-by "ctx:<slug>#iNNN"
```

## Что важно

**Вопрос закрывается ссылкой, а не словом.** `--answered-by` указывает на
материал, факт или требование, которое дало ответ. Голое «отвечено» — это
утверждение, которому нечем возразить; ссылку проверяет линтер.

**Состояние не хранится, а выводится**: есть ответ — `answered`, есть отметки
«спрашивали» — `raised`, иначе `open`. Поэтому оно не может разойтись с
содержимым.

**`--raised-to` обязательно отмечай, когда вопрос ушёл человеку.** Иначе
следующая сводка поднимет его заново как новый, и ты второй раз спросишь то, что
уже спрашивал. Отметки накапливаются: спросили дважды — две записи.

**`--impact` — что меняется от ответа.** Это то, что отличает важный вопрос от
любопытства, и по нему сводка расставляет приоритет.
