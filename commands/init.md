Используй навык **mnemo:chat-export**.

Задача: подготовить каталог экспорта в текущем проекте.

1. **Сначала поищи существующий экспорт** — `chat_export/`, `_chat-export/`,
   `ChatExport_*/`, либо любой каталог, где рядом `raw/` и `INDEX.md`.
   Порядок приёмки — `references/adoption.md` в навыке.
   - Нашёл `MANIFEST.json` → экспорт уже по стандарту. Ничего не делай, скажи об этом.
   - Нашёл самодельный → режим приёмки: разбери, **покажи план и дождись
     подтверждения**, только потом переноси. Копируй, не перемещай. Исходный
     каталог не удаляй.
   - Не нашёл → обычное создание.

2. Создание: `python3 ${CLAUDE_PLUGIN_ROOT}/scripts/mnemo_manifest.py init --dir <path> --slug <kebab> --title <...>`
   Скрипт сам исключит каталог из git хост-проекта и соберёт производные.

3. Спроси участников и проект, если они не очевидны из контекста.

Аргумент пользователя: $ARGUMENTS
