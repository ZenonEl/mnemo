argument-hint: Текст утверждения, источник и based_on

Используй навык **mnemo:reconcile**. Утверждение из нового пакета проводи через
JSON-план `review`. Для legacy-материала допустима прямая команда
`mnemo_manifest.py fact`.

Без конкретного `verification` запись остаётся `claim`. Не называй её
проверенной по словам вроде «проверял»; `verified_by` допустим только вместе с
проверяемым доказательством. Замена возможна только `fNNN → fNNN`.
