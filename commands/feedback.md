Используй навык **mnemo:reconcile**. Подготовь самодостаточный business brief:
без `ctx:`, внутренних id и технических деталей по умолчанию. Для однозначного
пакета используй `confirmation`; при коллизии или открытом решении —
`clarification` с одним главным вопросом.

Сохрани точный текст через `mnemo_manifest.py feedback`. Нематериальный пакет
можно отметить `--not-needed` только с содержательной причиной. Эта команда
ничего не отправляет; фактическая доставка отмечается отдельно.
