Используй навык **mnemo:chat-export**.

```
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/mnemo_verify.py --export <dir>
```

Правила V01–V20 описаны в `SPEC/STANDARD.md` §13. Покажи вывод человеку целиком.

Как читать типовые ошибки:

- **V02 хеш не совпал** — RAW изменён. Это нарушение основного правила стандарта.
  Разберись, что произошло, прежде чем запускать `rehash`. `rehash` — для случая
  легитимной замены (доложили оригинал), а не для того, чтобы заглушить ошибку.
- **V03 файл не учтён** — материал попал в `raw/` мимо команд. Заведи ему запись
  или убери файл.
- **V12 не исключён из git** — не косметика: рабочие данные могут уехать в чужой
  репозиторий. Чини сразу. Отдельный случай — «не удалось проверить git»: это
  тоже ошибка, а не мелочь. Незнание не равно разрешению.
- **V15/V16 контракты изъятий и людей** — нарушены инварианты, которые обычно
  не даёт нарушить сам инструмент. Значит, манифест правили руками.
- **V17 два материала на один файл** — содержимое одного затёрто другим.
  `rehash` тут запрещён: он сделает потерю невидимой.

Пересчитать хеши после законной замены RAW:
```
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/mnemo_manifest.py rehash --export <dir> \
  --confirm --reason "<чем объясняется замена>"
```
Без `--confirm` он только покажет расхождения и ничего не тронет.
